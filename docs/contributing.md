# Contribution Workflow

Idea → Feature → Implementation → Review → Merge → Release

1. Record the idea and assign a Feature ID.
2. Create or update the Feature document in `docs/features/`.
3. Confirm scope, constraints, and acceptance criteria before implementation.
4. Update the relevant design-system, decision, and roadmap documents.
5. Implement only the approved scope and preserve existing behavior.
6. Review the diff and validate the acceptance criteria before committing.
