# F-003－首頁 UI 調整

## Summary

精簡首頁 Dashboard 的首屏高度與資訊層級，並提高快速入口及重要備忘的操作效率。

## 主要調整

- 第一排 Timmy、今日運勢、天氣區高度約縮短三分之一並維持等高。
- 日期與星期移入 Timmy 卡片，移除獨立時鐘卡。
- 合併「地精程式師」與「Timmy 說」，移除 Timmy hover 放大。
- 快速前往改為左側原有圖示、右側標題與說明，間距 4px。
- 首頁「備忘錄」入口改名為「注意事項」。
- 首頁只顯示最近更新的 6 筆加星號備忘。
- 新增「新增備忘」與「瀏覽全部」，並沿用既有備忘功能。
- Footer 版本資訊降低 3px。

## Acceptance Criteria

- [x] 日期移入 Timmy 卡片且沒有日期圖示。
- [x] Timmy hover 不再放大或位移。
- [x] 快速前往保留原圖示並改為左右排版。
- [x] 首頁備忘只顯示加星號內容，最多 6 筆。
- [x] 新增與瀏覽入口沿用現有備忘頁及新增函式。
- [x] 空狀態可直接新增備忘。

### 本機測試方式

使用本機 HTTP server 開啟頁面；模擬資料不會在正式網址出現。首頁會顯示 2 筆加星號資料，「瀏覽全部」則會額外顯示 1 筆一般備忘，可用於驗證首頁篩選、排序及備忘錄列表。
